# Legacy GRUB/Multiboot implementation

Это снимок прежней реализации Tassux перед переходом на собственный
загрузчик. Исходники намеренно сохранены почти без изменений: после запуска
нового загрузчика отсюда можно постепенно вернуть консоль, прерывания,
драйверы, VFS и ext2.

Коммит `b228dda` содержит последнее состояние этой реализации непосредственно
перед переносом в данный каталог.

Локальные тяжёлые артефакты (`mydisk.img`, `kernel.bin`, `build/`, `uefi/`)
перенесены сюда вместе с исходниками, но по-прежнему игнорируются Git.
